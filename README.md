# Charley's Old Fashioned Hamburgers — website demo

Unofficial concept website prepared to show the owner. Not the restaurant's official site.

## Files
- `index.html` — page content (all text, menu cards, hours)
- `styles.css` — colours, fonts, layout
- `script.js` — mobile menu, menu tabs, gallery viewer, scroll effects

Photos are free stock images loaded from Unsplash, so there are no image files to upload.

## Free hosting (GitHub Pages)
1. Create a public repository on GitHub.
2. Upload `index.html`, `styles.css` and `script.js` (drag the three files, then Commit changes).
3. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
4. The site appears at `https://<username>.github.io/<repository-name>/` after a minute or two.
